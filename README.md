## 🎯 Why this Portfolio  

This portfolio website serves as my central, professional “home base” — a place where recruiters, employers, or collaborators can quickly:

- Understand my technical skills and tech stack  
- Explore my highlighted projects (with live/demo links + GitHub links)  
- Review my work experience, education, and certifications  
- Contact me for job opportunities or collaboration  

It ties together code (GitHub), live demos, and my personal branding.

- **Framework / Library:** Next.js (or React)  
- **Styling:** Tailwind CSS (responsive, modern UI)
